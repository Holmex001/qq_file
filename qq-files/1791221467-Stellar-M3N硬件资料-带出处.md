## 1. 产品参数（Stellar-M3N@ 系列）

- 尺寸 70 × 35 × 13.2 mm
- 重量 36 g
- 工作温度 0℃ ~ 30℃（手册注明：此温度为黑白电子纸屏幕的工作温度）
- 屏幕：2.1 吋 EPD 点阵电子纸，黑白 / 黑白红
- 分辨率：131 dpi（250 × 122 像素）
- 可视角度 >170°
- 电池：2 × 550 mAh，可更换（兼容汉朔标准电池盒）
- 电池寿命：5 年（每天 4 次价格更新）
- 峰值刷新速率：18000 个 / 小时（经商用基站）
- 三色 LED 闪光灯（促销/找货提示）
- NFC：按需提供；型号中带字母 N 即含 NFC 芯片
- 型号后缀含义（汉朔官方命名规则，由 ATC 项目引用汉朔提交给 FCC 的文件）：M3N@ 中 M = 2.13 吋、3 = 黑白红三色屏、N = NFC 芯片、@ = LED 灯；E31HA 中 H = 高分辨率、A = 无干簧管

## 2. 主控芯片：Telink TLSR8359

"带 N 的 Stellar 用的是 TLSR8359" 这一结论来自：

- 硬件识别指南列出的兼容型号表：Stellar-M3N@ E31HA，SoC = Telink TLSR8359
- ATC_TLSR_Paper 项目原文："This firmware requires hardware based on the TLSR8359 chip, which is usually the case for Stellar-xxNx models, but **not** models without an N"
- 不带 N 的型号（如 Stellar-M@）是另一款 SoC，不兼容此固件

芯片参数（以下全部出自，即 Telink 官方 DS-TLSR8359-E5）：

- CPU：32 位专有内核，最高 48 MHz，带指令缓存，官方称功耗性能优于 ARM Cortex-M0
- 芯片唯一 ID：4 字节 UID
- Flash：512 KB 内置（F512 版本；另有 64 KB 的 F64 版本；ET48 版本无内置 Flash，可外接最大 16 MB）
- SRAM：64 KB 片上，深睡眠最多保留 32 KB
- 射频（datasheet 原文列的是 2.4 GHz 专有协议模式）：1 Mbps / 2 Mbps / 250 kbps / 500 kbps，带自适应跳频 AFH；RX 灵敏度 -96 dBm @ 1 Mbps、-93 dBm @ 2 Mbps；TX 最高 +10 dBm；单引脚天线接口；RSSI 监测（±1 dB 精度）；自动应答 / 重传 / 流控
- 关于 BLE：datasheet 本身只列了上述专有协议模式；但 ATC_TLSR_Paper 作者实测 "As BLE can be enabled on the Telink TLSR8359"，开源固件实际就是跑 BLE 的
- 外设：SPI / I²C / UART（硬件流控）/ USB 2.0 全速 / Swire 调试接口；最多 32 / 17 / 2 个 GPIO（依封装）；6 路差分 PWM（含 IR 生成功能）；14 位 10 通道 SAR ADC（带 PGA）+ 温度传感器；正交解码器；硬件 AES 与 AES-CCM；低功耗比较器
- 时钟：24 MHz 与 32.768 kHz 晶振，内置 32 kHz / 24 MHz RC 振荡器；RTC、看门狗、3 路通用 32 位定时器、低功耗 32 kHz 定时器
- 功耗：深睡眠 0.4 µA（外部唤醒、无 SRAM 保持）；带 SRAM 保持时 8 KB / 16 KB / 32 KB 分别为 1 / 1.2 / 1.4 µA；整芯片 RX 5.3 mA，TX 4.8 mA @ 0 dBm（DCDC 开启）
- 供电：1.8 V ~ 3.6 V；工作温度 -40℃ ~ +85℃（ET 版本）

## 3. 显示屏与内存布局（出处：，项目 README "About the display" 章节）

- 250 × 122 像素，1-bpp，黑 = 0、白 = 1，无灰阶
- 显存按 90° 顺时针旋转布局（即实际是 122 宽 × 250 高，横着放）
- 每字节存 8 个像素，MSB 在左；122 像素的一行占 16 字节
- 像素地址公式（README 给的 SetPixel 示例）：`pDisplayBuffer[(y>>3) + (249-x)*16]`，位掩码 `0x80 >> (y&7)`

## 4. 二次开发 / 开源固件

- 原厂固件走加密、未公开的协议，只能配合汉朔商用基站使用，没有公开协议文档
- 方案：一次 UART 烧录，把原厂固件替换为开源固件 ATC_TLSR_Paper（作者 Aaron Christophel / atc1441）
- 烧录方法（项目 README "Flashing" 章节）：打开 WebSerial 烧录工具，载入编译好的.bin 写 Flash；首次连接需要先解锁 TLSR8359 的 Flash
- WebSerial 烧录工具：https://atc1441.github.io/ATC_TLSR_Paper_UART_Flasher.html
- 刷完后：价签以蓝牙广播名 `ESL_XXXXXX`（XXXXXX 为 6 位十六进制）出现，说明已装 ATC 固件，可直接用图传工具，无需再刷
- 图传 / OTA 工具（均出自项目 README）：
- WebBluetooth 图片上传：https://atc1441.github.io/ATC_TLSR_Paper_Image_Upload.html
- WebBluetooth 固件 OTA 烧录：https://atc1441.github.io/ATC_TLSR_Paper_OTA_writing.html
- 兼容型号（带 N、用 TLSR8359）：Stellar-MN@ E31H、Stellar-M3N@ E31HA、Stellar-MFN@ E31A、Stellar-S3TN@ E31HA；不带 N 的型号是另一款 SoC，不兼容
