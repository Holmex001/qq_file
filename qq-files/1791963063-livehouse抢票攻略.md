# Livehouse 抢票攻略

> 整理时间：2026-10-14。演出票务规则会变，下单前以演出页面说明为准。

## 一、主流购票平台

| 平台 | 定位 | 备注 |
|---|---|---|
| **秀动 ShowStart** | Livehouse 第一阵地 | 绝大多数 livehouse 演出在此售票；App / 微信小程序；支持预约抢票、电子票验票 |
| **大麦** | 综合演出平台 | 部分 livehouse、拼盘演出在此开票；退改规则透明 |
| **猫眼** | 综合演出平台 | 部分场次官方渠道；生态便捷 |
| **票星球** | 综合演出平台 | 演出覆盖广 |
| 官方公众号 / 小程序 | livehouse 自营 | 部分场馆（MAO 系等）有自己的售票入口，关注场馆官方号 |
| 摩天轮 / 票牛 | 聚合二手平台 | 可查演出信息，票价可能高于原价，注意确认是否官方授权 |
| 闲鱼等私下转票 | ❌ 高风险 | 假票、已核销票重灾区，不推荐 |

**一句话结论：** 认准演出官方公布的售票平台，livehouse 场景下九成是**秀动**。

## 二、livehouse 票的一般流程

1. **获取开票信息**：关注乐队 / livehouse 的官方微博、公众号，拿到准确开票时间。
2. **提前实名**：在秀动等 App 完成实名认证（姓名 + 身份证号），维护好支付方式。
3. **预约抢票**：在演出页点"预约"或"想看"，开票前会收到提醒。
4. **开票准时抢**：开票前 5–10 分钟进页面，多数演出**预售票秒没**。一般每人限购 2 张。
5. **及时支付**：抢到后支付一般限时 15 分钟，提前留足余额（微信/支付宝）。
6. **电子票入场**：livehouse 多为电子票，到场出示票码核销即可，通常不需要纸质票。
7. **没抢到怎么办**：关注平台的"缺货登记"（有人退票会释放）、演出当天可能放出现场票（现场票价通常高于预售）。

## 三、票种小知识

- **预售票**：提前买，便宜（一般 livehouse 80–200 元左右）。
- **现场票**：演出当天门口买（有余票才放出），比预售贵。
- **VIP / 套票**：少数演出有早鸟、双人套票等档位，下单前看清票种说明。

## 四、避坑清单

- 只从官方公布的渠道买票，不点陌生链接。
- 凡是"内部票""提前预定""付定金抢票"的，一律是诈骗。
- 私下转账、提前确认收货 = 骗局，坚决不做。
- 黄牛加价票、"代拍"在强实名下风险很高，能自己抢就别找代拍。
- 买错票一般不支持退（部分出票前可有条件退），下单前核对场次、时间、姓名。

## 五、抢票前的检查清单

- [ ] 秀动 App 已安装并实名认证
- [ ] 支付方式已绑定、余额充足
- [ ] 关注了乐队 / livehouse 官方号，知道开票时间
- [ ] 设了开票闹钟，提前 10 分钟进场
