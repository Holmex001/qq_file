# STM32 MCU 选型调研

> 需求：STM32 系列，≥2 个 ADC 外设，≥1 路 SPI，≥1 路 I2C
> 调研日期：2026-10-07

## 0. 需求解读：先确认"2*ADC"指什么

"2*ADC"有两种理解，选型结论不同，先对齐：

- **理解 A：2 个独立的 ADC 外设**（如 ADC1 + ADC2，可双 ADC 同步/交替采样）——这是字面含义，也是电机控制、功率测量等场景的典型需求。本文按此理解选型。
- **理解 B：只需要 2 个 ADC 通道**（1 个 ADC 外设扫 2 个通道就够）——那可选范围大得多，STM32F030 / G030 等单 ADC 的低成本型号也够用。

如果你实际是理解 B，告诉我一声，我再补一版低成本单 ADC 选型。

## 1. 结论速览

| 场景 | 推荐型号 | 一句话理由 |
|---|---|---|
| 综合首选（模拟/电机/电源） | **STM32G431KBT6** | 双 4Msps ADC + 片上运放/比较器/VREF，170MHz 带 FPU，32 脚好焊，价格适中 |
| 最低成本 / 资料最多 | **STM32F103C8T6** | 双 1Msps ADC，生态最成熟，注意买正品（假货重灾区） |
| C8 的 Flash/RAM/SPI 不够用 | STM32F103CBT6 | C8 的 128KB/双 SPI 版本，同封装可直接替换 |
| IO 多 / 程序大 / 资源要足 | STM32F407VET6 | 3 个 ADC、168MHz、512KB Flash，成熟稳定，贵一些、大封装 |
| 顶配备选（高端电机/数字电源） | STM32G474RET6 | 最多 5 个 ADC + HRTIM 高分辨率定时器 |

## 3. 各型号详解与选型注意

### 3.1 STM32G431KBT6 —— 综合首选

- **ADC**：ADC1 + ADC2，12bit、每路最高 4Msps（0.25μs），支持双 ADC 同步/交替/注入模式；硬件过采样可到等效 16bit。KBT6（32 脚）引出约 11 个外部通道，脚多版（RBT6，64 脚）通道更多。
- **模拟全家桶**：3 个运放（可配 PGA，省外部运放）、4 个高速比较器、4 路 DAC、内部基准缓冲 VREFBUF（可输出 2.048/2.5/2.95V 做 ADC 基准）。
- **算力**：170MHz Cortex-M4F，带 CORDIC（三角函数加速）、FMAC（滤波加速），做 FOC/数字电源很合适。
- **注意**：
  - 供电 1.71~3.6V，VDDA 必须独立供电+去耦（见第 4 节）；
  - 有的批次供货偏紧，下单前确认；
  - CubeMX + HAL/LL 开发，资料不如 F1 多，但官方例程齐全。

### 3.2 STM32F103C8T6 —— 最低成本 / 生态最熟

- **外设刚好够用**：ADC1+ADC2（双 ADC，1Msps）、1 路 SPI（SPI1）、2 路 I2C、3 路 USART、CAN、USB。
- **注意**：
  - **C8T6 只有 1 路 SPI**，128KB 的 CBT6 才有 2 路 SPI（见 3.3）；
  - **假货重灾区**：市面大量打磨片/换标片，务必走立创、得捷、贸泽等正规渠道；
  - 无 FPU、无 DAC，浮点运算靠软件，算法重则吃力；
  - I2C 外设有历史 errata（见第 6 节）；
  - 标准外设库已停更，新项目建议直接 HAL（CubeMX 生成）。

### 3.3 STM32F103CBT6 —— C8 的直接升级

- 与 C8T6 同 LQFP48 封装、引脚兼容，Flash 64KB→128KB，SPI 1 路→2 路，其余基本一致。
- C8 资源不够（程序超 64KB、要第二路 SPI）时直接换，不用改板。

### 3.4 STM32F407VET6 —— 资源/IO 要足时选

- 3 个 ADC（2.4Msps，支持双/三 ADC 模式）、3 路 SPI、3 路 I2C、168MHz、512KB Flash、82 个 IO。
- LQFP100 封装，手工焊接建议热风枪+拖焊；功耗明显高于 F1/G4。
- 生态成熟（正点原子/野火大量例程），适合功能复杂、IO 多的整机。

### 3.5 STM32G474RET6 —— 顶配备选

- G431 的大哥：最多 5 个 ADC、HRTIM 高分辨率定时器（217ps，数字电源/高频 PWM 利器）、512KB Flash。
- 只有高端电机控制、数字电源、多路同步采样才需要，贵且 64 脚起步。

## 4. ADC 选型与使用注意（重点）

1. **VDDA 必须供电**：F1/G4/F4 即使不用 ADC，VDDA/VSSA 也要接上（F1 的 ADC 不上 VDDA 会工作异常）。VDDA 引脚就近接 100nF + 1μF 去耦电容，模拟地与数字地单点连接。
2. **输入范围是 0~VDDA**（不是 VDD）：超量程会损坏 IO；被测信号先分压/运放调理到范围内。
3. **源阻抗 × 采样时间**：信号源内阻大时（如分压电阻>10k），必须加长 ADC 采样时间，否则采样电容充不满、读数偏低；实在不行加一级电压跟随器。F1 数据手册有"外部阻抗-采样时间"对照表，照表选。
4. **双 ADC 模式选型**：
   - 规则同步模式：u、i 同时采样算功率（单相/三相电测量典型用法）；
   - 交替（interleaved）模式：两路 ADC 交替采同一通道，采样率翻倍；
   - 注入同步模式：电机 FOC 的相电流同步采样常用；
   - 注意 F1 双 ADC 模式下，ADC2 的结果拼在 ADC1 数据寄存器的高 16 位，DMA 要按 32 位读。
5. **上电做一次 ADC 校准**：F1/G4 都有自校准功能，每次上电初始化时执行一次，消除零点/增益偏差。
6. **连续采集用 DMA + 双缓冲**：别用 CPU 轮询/中断逐个搬，特别是 Msps 级采样；数据右对齐。
7. **内部通道**：温度传感器、Vrefint 占用 ADC 内部通道（F1 是 ADC1 的 ch16/ch17）。Vrefint 有个妙用：用它反推当前 VDDA，电源波动时修正采样结果。
8. **基准电压**：F1/G4 的内部基准精度一般；高精度需求请外接基准芯片（如 REF3030）或直接用 G4 的 VREFBUF。
9. **ADC 时钟上限**：F1 的 ADCCLK ≤14MHz（对应 1Msps）；G4 可到 4~5Msps，注意分频配置。

## 5. SPI 使用注意

1. **CPOL/CPHA 必须与从机一致**：四种模式，接之前先看从机芯片手册的时序图，错了就全是乱码。
2. **片选建议用软件 GPIO**：多从机、时序复杂时，硬件 NSS 容易出幺蛾子（F1 主模式连续传输时尤其），GPIO 拉 CS 最省心。
3. **速率上限**：不超过 PCLK/2，同时不超过从机手册标的最大时钟；杜邦线飞线调试时先降速。
4. **DMA 收发**：SPI 是全双工，收发 DMA 配对使用；注意"先配好 DMA 再拉低 CS"的顺序。
5. **F1 引脚复用坑**：SPI1 默认 PA5/6/7，remap 到 PB3/4/5 时注意 PB4 默认是 JTAG 的 NJTRST，要先 AFIO 解锁才能当 GPIO/SPI 用。
6. 数据位宽 8/16 可配，高/低位先行（LSB/MSB）看从机要求。

## 6. I2C 使用注意

1. **上拉电阻必须接**：SCL/SDA 各一颗。400kHz 一般 2.2k~4.7k，100kHz 一般 4.7k~10k；总线电容大、从机多时阻值往小取。
2. **时钟拉伸**：从机可以拉低 SCL 拖时间，主机端要容忍（HAL 库默认支持），别用死等超时卡死。
3. **F1 的 I2C 有著名 errata**：上电毛刺可能导致 BUSY 标志卡死、总线锁死。规避方法：初始化前先把 SCL/SDA 配成 GPIO 输出拉高释放总线；出错时复位 I2C 外设再重新初始化。G4/F4 的 I2C 外设重写过，稳定得多，介意的话直接选 G4。
4. **地址冲突**：挂多个从机前先核对 7 位地址，别撞车；保留地址（0x00 等）别用。
5. **不适合长距离**：超过 30cm 或干扰大时降速到 100kHz，或改用 SPI/UART。

## 7. 硬件设计通用注意

1. **BOOT0**：正常运行接地（从 Flash 启动）；要用串口 ISP 下载时 BOOT0 接高再复位（F1）。
2. **SWD 调试口保留**：SWDIO/SWCLK 引出来，别被复用功能占死，否则调不了程序；NRST 接 10k 上拉 + 100nF 到地。
3. **晶振**：高速 8MHz 主晶振 + 负载电容按晶振规格书选（不是固定 20pF）；USB/CAN/FDCAN 必须用外部晶振（内部 HSI 精度不够）；RTC 的 32.768kHz 可选。
4. **电源去耦**：每对 VDD/VSS 就近 100nF；G4/F4 的 VCAP 引脚按手册接 2.2μF。
5. **5V 容忍**：F1 多数 IO 是 FT（5V 容忍），但 ADC 引脚（PA0~PA7 等）不是；G4 多数也是 FT。具体看数据手册引脚表的 "FT" 标记，别凭感觉接 5V。
6. **供货**：F1 是 2007 年的老型号但仍在产；G4 是现役主力。批量前跟供应商确认交期。
7. **开发环境**：CubeMX + HAL/LL（G4/F4）；F1 可用 HAL 或老标准外设库。调试器 ST-Link V2 即可。
