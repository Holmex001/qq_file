# Green Day 演出 DIY 穿搭指南

看 Green Day 演唱会，穿搭本身就是参与感的一部分。DIY 朋克风的核心只有一句话：**剪烂、缝补、别住、越做旧越对味**。

## 核心四套路

### 1. 魔改 T 恤
- 纯色黑 / 白 T 打底，用织物颜料手绘图案（歌词、专辑名、骷髅）
- 或买熨烫贴布，家里熨斗就能压
- 剪刀剪烂袖口、领口，下摆撕流苏——剪坏了就是朋克，不存在返工

### 2. 补丁 + 徽章
- 牛仔夹克 / 牛仔裤 / 背包上缝专辑封面、歌词布贴、刺绣徽章
- 越乱越好，不对称、留白、叠缝都是风格
- 不会缝纫机就用手缝针脚粗线，或者布胶临时贴

### 3. 别针装饰
- 安全别针别在裤脚、袖口、背带上
- 大号别针可以拼图案，甚至串联布片
- 别针一排别在牛仔裤侧缝是经典朋克元素

### 4. 二手改造
- 二手店淘大格纹衬衫、旧皮衣、老乐队 T，自己改
- 这本身就是朋克反消费主义，和演出气质天然贴合
- 皮衣加铆钉、链条，效果直接拉满

## 经典公式

- 基础版：破洞牛仔裤 + 乐队 T + 皮衣 + 匡威 / 马丁靴
- American Idiot 致敬版：黑衬衫配红领带
- 发型：莫西干头（见图二）
