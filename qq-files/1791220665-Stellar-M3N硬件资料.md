> 整理时间：2026-10-06。本文汇总公开资料（产品手册、社区逆向工程、芯片官方 datasheet），汉朔不开放官方开发文档，"N" 结尾型号另有开源固件可做二次开发。

## 2. 主控芯片：Telink TLSR8359

型号带 "N" 的 Stellar（M3N@ 等）用的是泰凌微 **TLSR8359** 无线 SoC。以下是官方 datasheet（DS-TLSR8359-E5）关键参数：

| 项目 | 参数 |
|---|---|
| CPU | 32 位专有内核（性能优于 Cortex-M0），最高 48 MHz，带指令缓存 |
| 唯一 ID | 4 字节 Chip UID |
| Flash | 512 KB 内置（F512 版本；另有 64 KB 的 F64 版本） |
| SRAM | 64 KB 片上（深睡眠可保留最多 32 KB） |
| 无线 | 2.4 GHz 多模：BLE 5.0 / IEEE 802.15.4 / 2.4 GHz 专有协议；单天线接口 |
| 发射/接收 | TX 最大约 +10 dBm；RX 灵敏度约 -96 dBm @1 Mbps |
| 外设 | SPI / I²C / UART（硬件流控） / USB / Swire 调试接口；最多 32 GPIO |
| 时钟 | 24 MHz & 32.768 kHz 晶振，内置 RC 振荡器；RTC、看门狗、多路 32 位定时器 |
| 睡眠功耗 | 深睡眠约 0.4 µA（无 SRAM 保持） |
| 供电 | 1.8 ~ 3.6 V |

> 厂家原厂固件走的是 2.4 GHz 专有加密协议，配合汉朔基站使用，协议不公开。

## 3. 显示屏与内存布局（社区实测）

- 屏幕是 250 × 122 像素 EPD，1-bpp，黑 = 0、白 = 1，无灰阶。
- 显存按 90° 顺时针旋转布局：每列连续 16 字节，每行 122 px 占 16 字节，总缓冲 250×16 = 4000 字节。
- 像素地址：`byte = (width−1−x) × 16 + (y>>3)`，`bit = 0x80 >> (y&7)`。
- 红通道（BWR 版本）为第二个独立 buffer plane。

## 4. 二次开发 / 开源固件

- **ATC_TLSR_Paper**（Aaron Christophel, atc1441）：给 TLSR 芯片的 BLE 自定义固件。**一次 UART 烧录**替换原厂固件后，价签以蓝牙广播 `ESL_XXXXXX` 出现，暴露单 GATT characteristic 完成图传/价格显示：
  - Service `13187B10-EBA9-A3BA-044E-83D3217D9A38`
  - Char `4B646063-6264-F3A7-8941-E65356EA82FE`
  - 命令：`0x00 0xFF` 清屏、`0x02 [hi][lo]` 设置偏移、`0x03 [data]` 写数据(≤239B)、`0x01` 刷新显示
- 烧录需要：CH340 等 3.3 V USB-串口、打开标签外壳接 TX/RX/GND/VCC，开机前短接使 SoC 进烧录模式，网页串口工具一键烧录。
- 兼容型号（带 N、用 TLSR8359）：Stellar-MN@ E31H、**Stellar-M3N@ E31HA**、Stellar-MFN@ E31A、Stellar-S3TN@ E31HA。不带 N 的型号是另一款 SoC，不兼容此固件。

## 6. 一点提醒

- 汉朔没有开放官方 SDK/API；**深度定制 = 必须拆机 UART 刷第三方固件**，原厂协议别指望破解。
- 刷机即脱保且失去与汉朔基站联用的能力，原电池盖卡扣拆装注意别掰断。
- 价签固件生态以 BLE 为主；如果你的场景需要 802.15.4/Zigbee，TLSR8359 硬件支持，但开源固件现阶段主要实现了 BLE 路径。
